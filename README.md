# B-Score Studio

B-Score Studio is a browser-based Credit Risk Scorecard Development platform for building, validating, and deploying credit scorecards from raw CSV data.

## Key Features

- Data Profiling & Quality Checks
- Fine and Coarse Binning
- WoE & IV Analysis
- IV-Based Feature Screening
- Sequential Feature Selection (SFS)
- Variable Clustering
- VIF Validation
- Logistic Regression Modeling
- Coefficient & P-Value Analysis
- Scorecard Generation
- Risk Ranking & Decile Analysis
- Interactive Visualizations
- CSV Export Reports

## How to Use

1. Upload a CSV file containing features and a binary target variable.
2. Review data profiling results.
3. Perform Fine and Coarse Binning.
4. Analyze WoE and IV.
5. Complete feature selection (IV → SFS → Clustering → VIF).
6. Train the Logistic Regression model.
7. Review model metrics and statistical significance.
8. Generate the scorecard.
9. Analyze risk ranking and deciles.
10. Export reports.

## GitHub Pages Deployment

1. Rename the application file to `index.html`.
2. Create a GitHub repository.
3. Upload `index.html` and `README.md`.
4. Go to **Settings → Pages**.
5. Select **Deploy from Branch**.
6. Choose **main** branch and **/(root)** folder.
7. Save and wait for deployment.

Your application will be available at:

`https://YOUR_USERNAME.github.io/REPOSITORY_NAME/`
